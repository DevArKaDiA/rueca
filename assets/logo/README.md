# Rueca logo

The mark is an R: the stem, a spinning wheel as the bowl, and a bobbin of
curly braces `{ }` with the thread wound between as the leg. The thread leaves
the wheel and runs into the bobbin.

| File | Use |
|---|---|
| `rueca.svg` | primary mark, dark ink, transparent (light backgrounds) |
| `rueca-on-dark.svg` | primary mark, light ink, transparent (dark backgrounds) |
| `rueca-light.svg`, `rueca-dark.svg` | primary mark on a solid square background |
| `rueca-small*.svg` | simplified glyph for 48 px and below (favicons, small icons) |
| `rueca-social-{light,dark}.{svg,png}` | 1280×640 social preview |
| `rueca-avatar-512.png` | avatar (fits GitHub's circular crop) |
| `rueca-favicon-256.png` | favicon source |

Colors: ink `#16181D` / `#ECEEF2`, thread `#E8451F` / `#FF5A2E`, backgrounds
`#FFFFFF` / `#0D1117`.

All files are generated by `gen.py` (`python3 gen.py rueca`; PNGs with
`rsvg-convert`). Edit the script rather than the SVGs. The logo is licensed
with the project (Apache-2.0); please don't use it to imply endorsement.
